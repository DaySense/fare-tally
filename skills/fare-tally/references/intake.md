# Interview / 主动提问

Use the user's language. Begin with the largest price/feasibility drivers; then ask only unresolved questions. Offer airport suggestions for approval when a novice knows only cities.

## First batch / 第一轮示例

CN: “开始查价前，先确认几件会影响结果的事：从哪里到哪里，哪一年、几位同行、什么舱位？出发及返回最早／最晚是哪几天，是否有必须抵达的时间？两端或中途还有哪些机场可以接受？**可接受的机场越多，越有机会找到更低票价，但也要算地面交通费和时间。** 不熟悉机场的话，告诉我城市和可接受的交通时长即可。你更看重最低票价、总花费，还是低价且时刻舒适？需要什么手提及托运行李，能接受廉航和中转吗？”

EN: “Before searching, where are you flying, in which year, with how many travelers and which cabin? What are the earliest/latest outbound and return dates, and any hard arrival deadline? Which nearby airports could work at either end or intermediate stops? **More acceptable airports can expose lower fares, but we should include ground costs and time.** If you do not know the airports, share the cities and ground-travel limit. Should I prioritize airfare, total spend, or low fares with reasonable timing? What cabin/checked bags do you need, and are budget airlines and connections acceptable?”

Split this into manageable questions; preserve what is already known.

## Follow up only where relevant / 按需追问

| Area / 项目 | Resolve / 要确认的内容 |
|---|---|
| Outbound / 去程 | Inclusive dates **and time windows**, year, school/work commitments, first/last usable local departure |
| Return / 回程 | Departure **dates and times** separately from latest **arrival**; full date/time/zone, overnight arrivals |
| Stay / 停留 | Hotel nights vs usable days; range per city and total nights; city order; weekend/event rules; accepted 2-night/airport-night exceptions |
| Airports / 机场 | Alternatives on each leg independently; return to same airport? Open jaws, cross-border ground travel, transfer time, transport/parking costs |
| Cost / 费用 | Currency and per-person/whole-party basis; airfare vs total budget; comfort premium; unknown costs |
| Bags / 行李 | Personal item, carry-on and checked pieces/weight on every carrier; equipment and required inclusions |
| Carrier / 航司 | Low-cost yes/no/conditional; excluded airlines; refund/change needs; fare family; membership benefits |
| Connections / 中转 | Maximum stops/layover/total travel time; overnight/red-eye; airport changes; self-transfer/separate-ticket acceptance |
| Needs / 特殊需要 | Child/infant age band at departure if fare-relevant; assistance if volunteered; traveling together; mandatory dates |
| Documents / 证件 | Nationality/passport type and relevant visas/residence **only when routing needs it**; no numbers or document uploads |
| Sources / 来源 | Preferred platforms, airline-direct checks, member/coupon eligibility, login session |
| Effort / 范围 | Date bounds, depth/time budget, complete matrix vs explicit sampling, allowed exclusions |

Offer concrete defaults when the user is unsure, then confirm material choices. Do not demand irrelevant sensitive details or repeat answered questions.

## Login wording / 登录说明

CN: “这一步需要在我正在使用的携程浏览器里登录，才能看到这里的会员／后续多程报价。你另一个浏览器的登录状态不一定共享。请你自行输入密码、验证码并完成验证，不要发给我；完成后告诉我。我只查价，不会代你下单或付款。”

EN: “This step needs a login in the Ctrip/Trip.com session I am using to view the relevant member or multi-city fares. Your other browser may not share it. Please enter your password, OTP and any verification yourself; do not send them to me. I will resume once the page confirms login. This is fare research, not booking or payment.”

Name the actual platform. Explain usable anonymous search if available; do not make login universally mandatory.

## Short agreement / 查价前短确认

Summarize hard constraints, flexible airports/dates/times/stays, permitted exceptions, currency/party basis, sources and coverage size. Resolve material unknowns before dependent searches. One acknowledgement suffices; existing authorization for the same concrete scope persists.
